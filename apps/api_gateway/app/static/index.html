Conversation LLM (Ollama)

Audio-native STT — Qwen3-Omni (MLX, Apple GPU) experimental

Audio → Vietnamese text in one step (no Whisper), with punctuation & casing. Heavy (30B MoE, ~1s/utterance). Pick a quant to download, then select engine qwen_omni.

Conversation LLM — Online (OpenAI-compatible)

Use a hosted OpenAI-compatible provider instead of local Ollama. For local models, just activate one in the “Conversation LLM (Ollama)” list above — no setup here. The API key is sent to the gateway and held in memory only (not persisted, not saved to the browser).

Conversation voice

Speak naturally — VAD detects when you pause to end your turn, transcribes it, generates a reply, and speaks it back. Configure an OpenAI-compatible LLM (CONVERSATION_LLM_BASE_URL) for real replies; otherwise a built-in echo responds.

Active models will appear here when the session starts.
